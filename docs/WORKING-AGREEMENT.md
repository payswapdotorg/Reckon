# Reckon Working Agreement

The repository is deliberately designed so TL3 can operate without access to the original product-design conversation.

The complete approved context is captured in:

- implementation context;
- frozen architecture;
- architecture lock;
- public contracts;
- ADRs;
- dependency graph;
- work-item state;
- worker handoffs;
- research references.

When the repository conflicts with a worker's recollection or external prose, repository evidence and the current architecture lock win.

External research can inform future ACRs, but it does not silently modify the frozen design.

Current baseline is intentionally architecture-ready, implementation pending.
