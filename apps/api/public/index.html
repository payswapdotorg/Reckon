Reckon API

Decision infrastructure for attention-aware agents. This is the public API deployment (DEPLOY-001, free tier).

  • GET /healthz — liveness (no auth)
  • GET /readyz — readiness + handler wiring map (no auth)
  • /v1/* — the frozen public contract surface (bearer key required)
Served by a Vercel serverless function — the self-contained production composition over PostgreSQL.
